<h2 style="margin:0 0 .6em;color:#6b3f1d;">✨ What Can It Do for You?</h2>
<p style="margin:0;color:#5b4a35;">If you manage books, organize excerpts, and develop reading notes in SiYuan, this plugin can handle much of the repetitive work for you. Start with a book title or ISBN, or sync your WeRead data directly, then organize book metadata and reading content in your own SiYuan knowledge base.</p>

<p style="margin:0;color:#665640;">Write the title, author, publisher, ISBN, cover, and other metadata into a SiYuan database.</p>
</div>
<div style="padding:1.15em;background:#fffaf0;border:1px solid #dfc998;border-radius:14px;box-shadow:0 5px 16px rgba(91,58,30,.06);">

<h2 style="margin:0 0 .35em;color:#6b3f1d;">🧭 Quick Start</h2>
<p style="margin:0 0 1em;color:#705d45;">For your first setup, follow the sequence below to establish a complete reading-management workflow more quickly.</p>
<div style="display:grid;grid-template-columns:repeat(auto-fit,minmax(240px,1fr));gap:12px;">
<div style="padding:1em;background:#f9f1dc;border-radius:12px;border-top:4px solid #7a3f18;">
<h3 style="margin:0 0 .35em;color:#6b3f1d;">1. Install and Open the Workbench</h3>
<p style="margin:0;color:#665640;">Install and enable the plugin from the SiYuan Marketplace, then open the Reading Notes Workbench from the plugin entry point.</p>
</div>
<div style="padding:1em;background:#f9f1dc;border-radius:12px;border-top:4px solid #7a3f18;">
<h3 style="margin:0 0 .35em;color:#6b3f1d;">2. Configure the Book Database</h3>
<p style="margin:0;color:#665640;">Select the database used to store book metadata and verify that its field mappings match your knowledge-base structure.</p>
</div>
<div style="padding:1em;background:#f9f1dc;border-radius:12px;border-top:4px solid #7a3f18;">
<h3 style="margin:0 0 .35em;color:#6b3f1d;">3. Configure the Note Template</h3>
<p style="margin:0;color:#665640;">Choose where reading notes are saved and which template to use, defining the structure of documents generated for newly imported books.</p>
</div>
<div style="padding:1em;background:#f9f1dc;border-radius:12px;border-top:4px solid #7a3f18;">
<h3 style="margin:0 0 .35em;color:#6b3f1d;">4. Connect WeRead</h3>
<p style="margin:0;color:#665640;">To sync WeRead, enter your API Key in the settings and adjust the synchronization options as needed.</p>
</div>
</div>
</div>

<div style="margin-top:1.4em;display:grid;grid-template-columns:repeat(auto-fit,minmax(280px,1fr));gap:14px;">
<div style="padding:1.35em;background:#fff7ed;border:1px solid #e5c69e;border-radius:14px;">
<h2 style="margin:0 0 .65em;color:#92400e;">🔎 Add Books from Douban</h2>
<ol style="margin:0;padding-left:1.3em;color:#5b4a35;">
<li style="margin:.4em 0;">Enter title keywords or an ISBN to search.</li>
<li style="margin:.4em 0;">Open the details and verify the author, publication information, and cover.</li>
<li style="margin:.4em 0;">Confirm the database record and note-document settings.</li>
<li style="margin:.4em 0;">Complete the import and continue managing the book from the local bookshelf.</li>
</ol>
</div>
<div style="padding:1.35em;background:#f3f8ed;border:1px solid #c9d9b6;border-radius:14px;">
<h2 style="margin:0 0 .65em;color:#365314;">📗 Sync WeRead</h2>
<ol style="margin:0;padding-left:1.3em;color:#53633d;">
<li style="margin:.4em 0;">Configure the API Key and choose what to synchronize.</li>
<li style="margin:.4em 0;">Click Update Sync or Full Sync.</li>
<li style="margin:.4em 0;">Review confirmations for new books and new public accounts.</li>
<li style="margin:.4em 0;">Review sync progress, result details, and follow-up tasks.</li>
</ol>
</div>
</div>

<div style="margin-top:1.4em;padding:1.45em;background:#fbf3dc;border-left:5px solid #9a3412;border-radius:14px;box-shadow:0 6px 18px rgba(122,63,24,.06);">
<h2 style="margin:0 0 .8em;color:#8a2e12;">🚀 WeRead Sync Capabilities</h2>
<ul style="margin:0;padding-left:1.25em;color:#5b4a35;">
<li style="margin:.4em 0;">Uses API Key mode instead of the legacy login-session synchronization method.</li>
<li style="margin:.4em 0;">Supports regular books, public-account profiles, and public-account articles.</li>
<li style="margin:.4em 0;">Supports highlights, thoughts, book reviews, popular highlights, and reading statistics.</li>
<li style="margin:.4em 0;">Checks local data before syncing and requests confirmation for new books and public accounts.</li>
<li style="margin:.4em 0;">Matches local books by ISBN, Book ID, and normalized title to reduce duplicate creation.</li>
<li style="margin:.4em 0;">Provides a bookshelf, sync progress, detailed results, and follow-up tasks for ongoing maintenance.</li>
</ul>
</div>

<div style="margin-top:1.4em;padding:1.45em;background:#eef6f8;border-left:5px solid #1f5f73;border-radius:14px;">
<h2 style="margin:0 0 .7em;color:#164e63;">🔐 Data and Credential Notes</h2>
<ul style="margin:0;padding-left:1.25em;color:#3f6670;">
<li style="margin:.4em 0;">WeRead synchronization requires your own API Key. Do not expose credentials in screenshots, feedback, or public repositories.</li>
<li style="margin:.4em 0;">Book metadata and sync results are written to the SiYuan knowledge base you select. Verify the database and template settings before a large synchronization.</li>
<li style="margin:.4em 0;">After your first setup or a template change, test with a small number of books before running a full synchronization.</li>
</ul>
</div>
