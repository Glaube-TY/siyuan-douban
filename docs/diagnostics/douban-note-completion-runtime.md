# 豆瓣笔记创建与补全：修改及验证记录

日期：2026-11-12（Asia/Shanghai）。基于插件 4.3.9 准备的 4.3.10 修复，以下为发布前验收记录。

## 修改内容

- 开启生成笔记时，先检查模板和保存位置；只有正文、真实文档身份和数据库绑定回读通过才返回成功。
- 创建失败、模板失败或绑定失败返回阶段和目标行/文档信息；已入库的记录显示笔记尚未完成。
- 现有详情框增加明确触发的“补全读书笔记”。补全复核唯一 ISBN、行 ID、标题、文档身份和保存位置，不重新添加数据库行。
- 已有正文直接保留，只恢复必要的绑定。空文档补写模板采用追加，不替换文档根块；并发用户编辑也不会被整篇覆盖。
- 绑定使用严格接口，明确区分行 ID 与文档 ID，由内核维护 custom-avs，保留已有数据库关联。
- 模板临时文件按操作隔离并清理，避免豆瓣操作与微信读书导入共用同一个可变文件。
- 正文可读不等于 SQL 文档索引已就绪。回查采用有界退避，累计等待间隔为 7.85 秒，不重复执行写入；超时保留已写内容并报告未确认状态。
- 新增提示与补全操作适配中文、英文。书架继续使用原来的真实文档校验。
- 发布前兼容复核发现微信读书默认模板为空。正文非空要求只用于豆瓣添加/补全；微信读书 BookID 和 ISBN 导入保留空模板及条件渲染为空的行为，随后继续由同步填充内容。
