## 实际软件验证

通过 HTTP 直连已打开的思源 3.8.10，确认运行工作空间与项目部署目标一致。使用项目 syncDevDeployment 加载候选程序并定向热重载；13 个程序文件与构建产物一致，复制 6 个、保持 7 个、删除 0 个。

临时验收插件在实际 desktop 客户端运行隔离的安装包副本，直接调用从该构建包识别出的公共请求、鉴权、分页及模板函数。合成回包只注入该隔离副本，未增加生产插件的测试接口或修改其全局网络行为。

- 业务数据附带升级通知时正常返回，不重复请求。
- 有效空书架仍可通过鉴权检查；通知单独返回、鉴权失败和业务拒绝继续报错。
- 两页笔记列表完整读取，count 与 lastSort 平铺，八个合成请求均上报 1.0.6。
- 升级诊断仅出现一次，不包含合成凭据或响应内容。
- 隔离验收文档的原有正文、子块 ID 不变；没有调用写笔记接口。
- 从实际插件读取原有加密配置，使用只读适配器，配置历史协议为 1.0.4；读取过程中没有配置写入。
- 使用该 API Key 完成一次真实 /shelf/sync 只读请求，协议为 1.0.6，返回正常书架结构，没有升级提示。

本设备自动同步原本为关闭状态，验收保持该设置；未发起书籍导入或全量/增量同步。
